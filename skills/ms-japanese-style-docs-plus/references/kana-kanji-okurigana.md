# かな・漢字・送り仮名の確認手順 - 公開資料ベース版

[Microsoft 日本語ローカリゼーション スタイルガイド](https://aka.ms/japanese-styleguide)
§4.1.3 が示す公開基準と辞典を拠り所にします。
2026 年 11 月 21 日に公式配布 PDF の該当節を確認しました。
辞典の語彙一覧は転載していません。
このファイルは確認手順であり、網羅的な辞書ではありません。

## 1. 拠り所

公開ガイドが指定する資料は次のとおりです。

- 「現代仮名遣い」 : ひらがなの使い方。
- 「常用漢字表」 : 漢字と音訓の範囲。
- 「送り仮名の付け方」 : 送り仮名。
- 『用字用語 新表記辞典』 (第一法規) : かな・漢字の使い分け、送り仮名、同音異義語。

規則の詳細が必要な場合は原本を確認します。辞典を確認できない語は、
辞典で確認済みであるかのように説明しません。

## 2. 確認の順序

1. 製品名、UI 名、引用した固定文字列でないか確認します。
   該当するものは正式な表記を維持します。
2. 文章中での語の意味を確認します。同じ読みだからといって一括置換しません。
3. 必要に応じて公開基準や指定辞典で、漢字、音訓、送り仮名を確認します。
4. 同じ文書で同じ意味に使う語の表記を揃えます。
5. 表記を確認できず意味に影響する場合は、その箇所を未確認と明示して利用者に確認します。

## 3. 公開ガイドで直接確認できる例

公開ガイド §4.1.3 は、カタカナには全角、英字には原則として半角を使うとしています。
月数や個数は、読みやすいかな・漢字の表記を使います。

```text
6 か月
8 個
```

固有名詞、製品名、UI 名は、これらの一般的な表記例より正式名称を優先します。
記号とスペースは [中心的なルール](./style-rules.md) に従ってください。
