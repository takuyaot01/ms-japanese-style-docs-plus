# ビジネス文書の組み立てと敬語

提案、報告、依頼、障害連絡などを、読み手が判断しやすい順に整えるための編集上の目安です。Microsoft 固有の表記要件ではなく、公用文の規則を民間の文書にそのまま当てはめるものでもありません。依頼を受けた Office の文面や、このスタイルを明示した文章相談に使い、送信や投稿は行いません。

## 1. 読み手と目的を決める

文化審議会 [『公用文作成の考え方』](https://www.bunka.go.jp/seisaku/bunkashingikai/kokugo/hokoku/pdf/93651301_01.pdf) の「基本的な考え方」2、I §§1–4、II §§2–7、III §§1–4 を、読みやすい説明の参考にします。まず何を伝え、何を判断・実行してほしいかを示します。説明的な見出し、1 文 1 要点、比べやすい箇条書きや表を使い、曖昧な時刻・条件・係り受けは意味を確かめて書き分けます。

| 用途 | 構成の目安 |
|---|---|
| 顧客向け提案 | 提案 → 読み手にとっての利点 → 適用条件・制限 → 次に相談・判断したいこと。一般提供 (GA) とプレビューは区別し、対象製品で確認できた場合だけ記載します。効果を保証したり、契約・権限を推定したりしません。 |
| 報告 | 結論または現状 → 確認済みの根拠と影響 → 決定事項と未決事項 → 次回の更新 (分かっていれば)。仮説を事実と混ぜません。 |
| 依頼 | 誰に何をお願いするか → 必要な背景 → 確認済みの期限・回答方法。時差が影響する場合は確認済みのタイムゾーンを添えます。未定の期限や依頼していない回答義務は加えません。 |
| 障害・難しい連絡 | 状況を受け止める言葉 → 確認済みの影響 → 調査状況 → 検証済みの回避策や確定した次回連絡。分からない原因、責任、復旧時刻を断定せず、約束を作りません。 |

## 2. 相手との関係に合わせた敬語

文化審議会 [『敬語の指針』](https://www.bunka.go.jp/seisaku/bunkashingikai/kokugo/hokoku/pdf/keigo_tosin.pdf) 第 2 章 第 2 の 6 (二重敬語と定着した言い方)、第 3 章 第 1 の 4 (過不足)、第 2 の 6 (「させていただく」)、第 3 の 5 (依頼) を参照します。

- 丁寧さは定型句の長さではなく、相手との関係、依頼の負担、文書の目的に合わせます。同じ種類の敬語をむやみに重ねませんが、定着した表現まで一律に誤りと扱いません。
- 「させていただく」は、相手や第三者の許可を受ける事情と、そのことで話し手側が恩恵を受ける文脈を確かめます。一律に禁止せず、事情がない定型句なら簡潔な丁寧語にします。
- 「弊社」は、書き手が実際に提供側の組織を代表して書くときだけ使います。担当者名や役割で伝わる場合、または所属が不明な場合は、推測で組織を代弁しません。宛名が必要なら相手が指定した呼び方を使えます。

### 自作の書き換え例

- 単に案の範囲を説明する場面 : 「対象範囲をご説明させていただきます。」→「対象範囲をご説明します。」許可と恩恵が明らかな場面は別に判断します。
- 確認範囲が決まっている依頼 : 「ご確認のほどよろしくお願い申し上げます。」→「対象範囲の記載をご確認いただけますか。」依頼したい行動を明示し、未定の期限は付けません。
- 報告で原因が未確定の場面 : 「設定が原因です。」と断定せず「原因は調査中です。」とします。調査が行われていること自体が確かでなければ「原因は確認できていません。」とします。
