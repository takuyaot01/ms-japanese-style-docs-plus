# MS Japanese Style Docs+

Microsoft の公開日本語スタイルガイドを参考に、作者が普段の資料づくりで使いたい **表記・文体・フォントの独自ルールをプラス**した、Microsoft 365 Copilot Cowork 用のスキルです。

日本語の PowerPoint、Word、Excel を作るときに、文章と見た目を整えるお手伝いをします。「かっこは半角だっけ?」「フォントがまた混ざってる...」を少し減らして、伝えたいことに集中するための相棒です。

**スキル名:** `ms-japanese-style-docs-plus`  
**バージョン:** v2.0.0 (更新日 2026 年 11 月 21 日)  
**作成者:** Takuya Ohta  
**対応形式:** `.pptx` / `.docx` / `.xlsx`

> 個人が作成したスキルで、Microsoft の公式配布物ではありません。独自ルールも含むため、公式ガイドそのものや、完全準拠を保証するものではありません。

## 導入方法

### 1. ZIP をダウンロード

**[導入用 ZIP をダウンロード](./ms-japanese-style-docs-plus.zip?raw=1)**

ダウンロードした `ms-japanese-style-docs-plus.zip` を、**展開せずに** Cowork にアップロードします。

### 2. Cowork に追加

1. Copilot を開きます。
2. 左側の **プラグイン** を開き、**Cowork** タブを選びます。
3. **追加 > アップロード** を選びます。
4. ダウンロードした `ms-japanese-style-docs-plus.zip` をアップロードします。
5. スキル一覧に `ms-japanese-style-docs-plus` が表示されれば、追加できています。

参照ファイルも使うので、`SKILL.md` だけではなく ZIP ごとアップロードしてください。同名のスキルがあると番号付きで追加されることがあるため、重複していないかも見ておくと安心です。

手順は [Cowork の公式カスタマイズ手順](https://learn.microsoft.com/en-us/copilot/cowork/cowork-customize) を参考にしています (2026 年 11 月 20 日確認)。画面の名前や配置が違う場合は、公式手順もご覧ください。

### 補足 : OneDrive に直接置く場合

個人スキル用フォルダーに直接置く方法を使っている環境では、ZIP を `ms-japanese-style-docs-plus` フォルダーに展開して、OneDrive の次の場所にコピーすることもできます。

```text
ドキュメント\Cowork\skills\ms-japanese-style-docs-plus
```

コピーしたフォルダーの直下に `SKILL.md`、その下に `references` フォルダーと参照ファイルがあれば OK です。同名フォルダーを更新するときは、先にバックアップしておきましょう。

保存先は環境によって違い、`Coworker` という名前の場合もあります。フォルダー名を推測せず、実際の保存先を確認してください。初めて使う方は、上のアップロード手順がおすすめです。

## 使用方法

追加・更新したら、新しい会話でこんなふうに頼んでみてください。

```text
ms-japanese-style-docs-plus を使って、添付の製品説明を日本語の提案スライドにしてください。
お客様向けに、分かりやすく丁寧な文章にしてください。
```

## できること

| 項目 | こんなふうに整えます |
|---|---|
| 見出し | タイトルや列見出しは短くすっきり。原則は体言止め |
| 本文 | 説明や注記は、ですます調で読みやすく |
| 表記 | 句読点、半角・全角、スペースのばらつきを整理 |
| 語彙 | 堅い言葉や回りくどい表現を、文脈に合う自然な日本語に |
| トーン | 読み手や用途に合わせて、分かりやすく丁寧に |
| フォント | 日本語に `Yu Gothic UI`、英数字・半角記号に `Segoe UI` を指定 |
| Excel データ | 数値、数式、ID は文体調整の対象外。整えるのは文章やラベル |

名前の「+」には、半角記号への統一、コロン前後のスペース、中黒による並列表記、フォントの固定といった独自ルールも含まれます。これらは公式ガイドと異なる場合も優先する、作者の選んだルールです。Microsoft の必須ルールというわけではありません。

## 仕組みと前提条件

このスキルが担当するのは文章と表記。ファイルを作る作業は、Cowork の組み込み `pptx` / `docx` / `xlsx` スキルに任せます。

- 個人スキルと文書生成機能が使える Copilot Cowork 環境で利用できます。
- 元になる情報や資料を渡してください。Microsoft 365 の情報を使うときは、検索機能とアクセス権も必要です。
- フォント本体は含まれていません。できあがった資料は Office アプリで開いて、フォントとレイアウトをひと目チェックしてください。

得意分野は、日本語の Office 資料づくりです。英語のみの資料、PDF の生成、ファイルを作らない文章レビューは主な対象にしていません。

## 作った人と、このスキルのこと

作者は Microsoft で、こんな「伝える」仕事に携わってきました。

- **カスタマー サポート (9 年)**  
  サポート回答、ホワイトペーパー、Microsoft Learn の執筆
- **ソリューション エンジニア (10 年・現在)**  
  プレゼン、デモ、イベント登壇

文章で伝える場面でも、人前で話す場面でも、資料はいつもの仕事道具。そんな日々の資料づくりに使いやすいよう、公開ガイドに独自ルールを足したのが、この 「Docs+」 です。資料の表記に使う時間を少し減らせたら嬉しいです。なおプレゼン時の緊張を取る機能はまだ付いていません。
